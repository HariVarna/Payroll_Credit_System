===================================================================
         SEPOLIA DEPLOYMENT & VERIFICATION RUNBOOK
===================================================================

Prerequisites:
1. Copy .env.example to .env
   powershell: Copy-Item .env.example .env
2. Configure variables in .env:
   - SEPOLIA_RPC_URL (e.g. Infura / Alchemy endpoint)
   - PRIVATE_KEY (Hex string of wallet holding Sepolia test ETH)
   - ETHERSCAN_API_KEY (API key from etherscan.io)
3. Ensure the wallet has at least 0.05 Sepolia ETH for gas.

Validation command:
node scripts/check-env.js

Live Deployment Commands:
1. Deploy both contracts:
   npm run deploy:sepolia
   (or: npx hardhat run scripts/deploy.js --network sepolia)

2. Deploy individually if preferred:
   npm run deploy:config:sepolia
   npm run deploy:token:sepolia

Source Code Verification Commands:
(Replace placeholders with actual contract addresses emitted by deploy script)
npx hardhat verify --network sepolia <DEPLOYED_PAYROLL_CONFIG_ADDRESS>
npx hardhat verify --network sepolia <DEPLOYED_PAYROLL_CREDIT_ADDRESS>

Live Contract Interaction Commands:
$env:PAYROLL_CONFIG_ADDRESS="<DEPLOYED_PAYROLL_CONFIG_ADDRESS>"
npx hardhat run scripts/interact-config.js --network sepolia

$env:PAYROLL_CREDIT_ADDRESS="<DEPLOYED_PAYROLL_CREDIT_ADDRESS>"
npx hardhat run scripts/interact-token.js --network sepolia

Sepolia Block Explorer:
https://sepolia.etherscan.io
